# ChatBotWithLLM

C# WinForms ile geliştirilmiş, Groq API kullanan uzay temalı chatbot uygulaması.

## ✨ Özellikler

- 🚀 **Groq API Entegrasyonu** - Hızlı ve ücretsiz LLM desteği
- 🎨 **Uzay Temalı Arayüz** - Satürn gezegeni ve yıldızlı arka plan
- 💬 **Sohbet Geçmişi** - Renkli mesaj baloncukları
- ⚙️ **Kolay Ayarlar** - API anahtarı yönetimi
- 🛡️ **Limit Koruması** - Ücretsiz kota dolduğunda otomatik durdurma

## 📋 Gereksinimler

- .NET Framework 4.8
- Visual Studio 2022 veya üzeri
- Groq API anahtarı ([console.groq.com](https://console.groq.com))

## 🚀 Kurulum

1. Projeyi klonlayın veya indirin
2. Visual Studio'da açın
3. `ChatBotWithLLM.sln` dosyasını açın
4. Projeyi derleyin (F6)
5. Çalıştırın (F5)

## ⚙️ Yapılandırma

1. Uygulamayı başlatın
2. **Ayarlar** butonuna tıklayın
3. Groq API anahtarınızı girin
4. API URL'i kontrol edin (varsayılan: `https://api.groq.com/openai/v1/chat/completions`)
5. **Kaydet** butonuna tıklayın

## 💡 Kullanım

1. Alttaki metin kutusuna mesajınızı yazın
2. **Gönder** butonuna tıklayın veya Enter'a basın
3. Bot yanıtını bekleyin
4. Sohbet geçmişi otomatik olarak kaydedilir

## 🎨 Tema

- **Arka Plan**: Koyu mavi-mor gradient, yıldızlı gökyüzü
- **Satürn Gezegeni**: Sağ üst köşede, altın halkalı
- **Mesaj Renkleri**: 
  - Bot: Açık gri-mavi
  - Kullanıcı: Bordo
  - Butonlar: Bordo arka plan, altın kenarlık

## ⚠️ Notlar

- Groq ücretsiz kotası dolduğunda sohbet otomatik durur
- API anahtarı güvenli bir şekilde kaydedilir
- İnternet bağlantısı gereklidir

# OpenRouter Kullanım Rehberi 🚀

## ✅ OpenRouter Nedir?

OpenRouter, birçok farklı AI modeline erişim sağlayan bir **API gateway** hizmetidir. OpenAI, Google, Meta gibi birçok modeli tek bir API üzerinden kullanabilirsiniz.

---

## 💰 FİYATLANDIRMA

- **Ücretsiz kredi** verir (ilk kayıtta)
- **Kullanım başına ücret** (model ve token sayısına göre)
- **Limit bittiğinde** hata verir (ekstra ücret alınmaz)
- Krediniz bittiğinde sohbeti kesebilirsiniz

---

## 🔑 API KEY ALMA

### Adım 1: Kayıt Olun
1. Tarayıcıda açın: **https://openrouter.ai**
2. "Sign Up" veya "Kayıt Ol" butonuna tıklayın
3. Google hesabı ile giriş yapabilirsiniz

### Adım 2: API Key Oluşturun
1. **https://openrouter.ai/keys** adresine gidin
2. "Create Key" veya "Anahtar Oluştur" butonuna tıklayın
3. Key'i kopyalayın (tekrar gösterilmez!)

### Adım 3: Ücretsiz Krediyi Kontrol Edin
1. **https://openrouter.ai/activity** adresine gidin
2. Kalan kredinizi görebilirsiniz
3. Limit dolunca sohbeti kesin

---

## 🎯 UYGULAMADA KULLANIM

### 1. Ayarlara Gidin
- Uygulamayı açın
- **"Ayarlar"** butonuna tıklayın

### 2. OpenRouter Seçin
- "Sağlayıcı" dropdown'ından **"OpenRouter"** seçin

### 3. API Key'i Girin
- API key'inizi yapıştırın
- URL otomatik ayarlanacak: `https://openrouter.ai/api/v1/chat/completions`

### 4. Kaydedin ve Test Edin
- **"Kaydet"** butonuna tıklayın
- Mesaj yazıp test edin

---

## 📊 MODELLER

OpenRouter birçok modeli destekler:
- `openai/gpt-3.5-turbo` (Varsayılan)
- `google/gemini-pro`
- `meta-llama/llama-3.1-8b-instruct:free` (Ücretsiz model)
- Ve daha fazlası...

**Model listesi:** https://openrouter.ai/models

---

## ⚠️ LİMİT KONTROLÜ

### Limit Bittiğinde Ne Olur?

Uygulama otomatik olarak şu hatayı gösterir:
```
⚠️ LIMİT AŞILDI! OpenRouter krediniz bitti. 
Lütfen kontrol edin: https://openrouter.ai/activity
```

**Bu durumda:**
- ✅ Ekstra ücret alınmaz
- ✅ Sohbeti kesebilirsiniz
- ✅ Yeni kredi ekleyebilirsiniz (isteğe bağlı)

---

## 💡 ÖNERİLER

1. **Başlangıç:** Ücretsiz krediyi kullanın
2. **Limit kontrolü:** https://openrouter.ai/activity sayfasından takip edin
3. **Limit dolunca:** Başka bir provider'a geçin (Google Gemini ücretsiz tier)
4. **Model seçimi:** Ücretsiz modelleri kullanın (`meta-llama/llama-3.1-8b-instruct:free`)

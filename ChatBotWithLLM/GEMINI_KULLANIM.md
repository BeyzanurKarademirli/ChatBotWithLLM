# Google Gemini Pro Kullanım Rehberi 🚀

## ✅ Harika Haber!
Gemini Pro hesabınız varsa, uygulamayı hemen kullanabilirsiniz!

---

## 📋 ADIM 1: API Key Alma

1. **Google AI Studio'ya gidin:**
   - https://aistudio.google.com/app/apikey
   - Google hesabınızla giriş yapın (Pro hesabınızla)

2. **API Key Oluşturun:**
   - "Create API Key" veya "API Key Oluştur" butonuna tıklayın
   - Key'inizi kopyalayın (güvenli bir yere kaydedin)

3. **Not:** Öğrenci hesabınızla aldığınız Pro erişimi, API kullanımında da geçerlidir! ✅

---

## 🎮 ADIM 2: Uygulamada Ayarlama

1. **ChatBot uygulamanızı açın**

2. **Ayarlar butonuna tıklayın** (sağ alt köşe)

3. **Provider Seçimi:**
   - "Sağlayıcı" dropdown'ından **"Google Gemini (Ücretsiz)"** seçin

4. **API Key Girin:**
   - API Anahtarı alanına kopyaladığınız key'i yapıştırın
   - URL otomatik olarak güncellenecek

5. **Kaydet'e tıklayın**

6. **Hazırsınız!** 🎉

---

## 🔧 Model Seçenekleri

Uygulama şu anda **gemini-pro** modelini kullanıyor. Bu:
- ✅ Gemini Pro'nun standart modeli
- ✅ Öğrenci hesabınızla çalışır
- ✅ Genel kullanım için mükemmel

**Not:** Gerekirse kodda model adını değiştirebilirsiniz (örn: gemini-1.5-pro)

## ❓ Sorun Giderme

### API Key çalışmıyor:
- Key'i doğru kopyaladığınızdan emin olun
- Google AI Studio'dan yeni bir key oluşturmayı deneyin
- Pro hesabınızın aktif olduğunu kontrol edin

### Yanıt almıyorum:
- İnternet bağlantınızı kontrol edin
- API key'inizin doğru olduğundan emin olun
- Hata mesajını kontrol edin (kırmızı renkte gösterilir)

# Ücretsiz LLM Alternatifleri 🆓

## ✅ TAMAMEN ÜCRETSİZ

### 1. **DeepSeek** ⭐ (ÖNERİLEN)
- ✅ **Tamamen ücretsiz**
- ✅ OpenAI uyumlu (sorunsuz çalışır)
- ✅ Hızlı yanıtlar
- ✅ Türkçe desteği mükemmel
- ✅ API key: https://platform.deepseek.com/api_keys
- ✅ Model: `deepseek-chat`

**Kurulum:**
1. https://platform.deepseek.com/api_keys → API key oluştur
2. Uygulamada: Ayarlar → "DeepSeek (Ücretsiz/Önerilen)"
3. API key'i yapıştır → Kaydet

---

### 2. **Google Gemini**
- ✅ **Ücretsiz** (API key ile)
- ⚠️ Bazı kullanıcılarda sorun yaşanabiliyor
- ✅ API key: https://aistudio.google.com/app/apikey
- ✅ Model: `gemini-1.5-flash`

**Not:** Gemini'de sorun yaşıyorsanız DeepSeek kullanın.

---

### 3. **Ollama** (Yerel)
- ✅ **Tamamen ücretsiz**
- ✅ İnternet gerektirmez
- ✅ Verileriniz bilgisayarınızda kalır
- ⚠️ Model indirmeniz gerekir (1-7 GB)
- ✅ Kurulum: https://ollama.com

**Kurulum:**
1. Ollama'yı indirip kurun
2. Terminal'de: `ollama pull llama2` (veya başka model)
3. Uygulamada: Ayarlar → "Ollama (Yerel/Ücretsiz)"
4. Model seçin → Kaydet

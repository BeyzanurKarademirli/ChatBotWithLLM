# Gemini API Key Bulma Rehberi 🔑

## 📍 Şu An Neredesiniz?
"Projeler" sayfasındasınız. Projeniz var: **"sohbet robotu"** ve **"1 anahtar"** gösteriyor.

---

## ✅ API Key'i Bulmak İçin:

### ADIM 1: API Keys Sayfasına Gidin
1. Sol menüden **"API anahtarları"** (API keys) linkine tıklayın
2. Veya tarayıcıda direkt şu adrese gidin: https://aistudio.google.com/app/api-keys

### ADIM 2: Key'inizi Bulun
- Listede projenizdeki key'i göreceksiniz
- Key'in yanında kopyala ikonu olacak
- Tıklayarak key'i kopyalayın

### ADIM 3: Yeni Key Oluşturmak İsterseniz
1. "API anahtarı oluşturun" butonuna tıklayın
2. Projenizi seçin (sohbet robotu)
3. Key otomatik oluşturulur
4. Hemen kopyalayın!

---

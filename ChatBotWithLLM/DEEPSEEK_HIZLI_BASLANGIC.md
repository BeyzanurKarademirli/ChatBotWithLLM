# DeepSeek Hızlı Başlangıç 🚀

## ✅ ADIM ADIM KURULUM

### 1. API Key Oluşturma

#### Adım 1: DeepSeek Platform'a Gidin
- Tarayıcıda açın: **https://platform.deepseek.com/api_keys**
- Veya: https://platform.deepseek.com → "API Keys" sekmesi

#### Adım 2: Giriş Yapın / Hesap Oluşturun
- Google hesabı ile giriş yapabilirsiniz
- Veya e-posta ile kayıt olun

#### Adım 3: API Key Oluşturun
- "Create API Key" veya "API Anahtarı Oluştur" butonuna tıklayın
- Key otomatik oluşturulur
- **ÖNEMLİ:** Key'i hemen kopyalayın! (Tekrar gösterilmez)

#### Adım 4: Key Formatı
- Key uzun bir string olacak (örn: `sk-xxxxxxxxxxxxxxxxxxxxx`)
- Başında/sonunda boşluk olmamalı
- Tüm karakterleri kopyalayın

---

### 2. Uygulamada Ayarlama

#### Adım 1: Uygulamayı Açın
- Projeyi çalıştırın (F5 veya Debug)

#### Adım 2: Ayarlara Gidin
- Sağ alt köşedeki **"Ayarlar"** butonuna tıklayın

#### Adım 3: DeepSeek Seçin
- "Sağlayıcı" dropdown'ından **"DeepSeek (Ücretsiz/Önerilen)"** seçin

#### Adım 4: API Key'i Yapıştırın
- "API Anahtarı" alanına kopyaladığınız key'i yapıştırın (Ctrl+V)
- URL otomatik olarak ayarlanacak: `https://api.deepseek.com/v1/chat/completions`

#### Adım 5: Kaydedin
- **"Kaydet"** butonuna tıklayın
- Form kapanacak

#### Adım 6: Kontrol Edin
- Durum çubuğunda **"Hazır (DeepSeek)"** yazmalı
- Eğer görünmüyorsa, uygulamayı yeniden başlatın

---

### 3. Test Edin

1. Mesaj yazın (örn: "Merhaba, nasılsın?")
2. **"Gönder"** butonuna tıklayın
3. DeepSeek'ten yanıt gelmeli! ✅

---

## ❓ SORUN GİDERME

### Sorun: "API anahtarı ayarlanmamış"
**Çözüm:** Ayarlardan API key'i kontrol edin, tekrar yapıştırın

### Sorun: "API Hatası: Unauthorized"
**Çözüm:** 
- API key'i doğru kopyaladığınızdan emin olun
- Başında/sonunda boşluk olmamalı
- Yeni bir key oluşturup tekrar deneyin

### Sorun: "API Hatası: BadRequest"
**Çözüm:**
- URL'nin doğru olduğundan emin olun: `https://api.deepseek.com/v1/chat/completions`
- Provider'ın "DeepSeek" olduğunu kontrol edin
